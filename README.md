# 📜 오늘의 조선 야사 (朝鮮野史錄 — Joseon Daily Yasa)

> **역사 속 오늘(양력 날짜 기준), 《조선왕조실록》의 엄숙한 한 줄 기록 뒤에 숨겨진 흥미진진한 야사(野史)와 궁중 비화를 책 페이지처럼 읽는 미니멀 역사 리더 웹앱**

- 🌐 **웹앱 바로가기 (GitHub Pages)**: [https://manjaedo.github.io/joseon-daily-yasa/](https://manjaedo.github.io/joseon-daily-yasa/)
- 📦 **GitHub 저장소**: [https://github.com/manjaedo/joseon-daily-yasa](https://github.com/manjaedo/joseon-daily-yasa)

---

## ✨ 주요 기능 (Key Features)

1. **📅 날짜별 실록 & 야사 자동 매칭**
   - 접속한 오늘 날짜(월·일)에 실제로 일어났던 조선시대 사건과 야사를 자동으로 보여줍니다.
   - `‹ 어제` / `내일 ›` 이동, 달력 날짜 직접 선택, `오늘` 복귀, `랜덤 날짜` 탐색을 지원합니다.

2. **📜 상단 '오늘자 야사 제목 바로가기' 목차 (Quick Jump List)**
   - 카테고리 탭 바로 아래에 해당 날짜(또는 명장면 모음)의 전체 야사 제목 리스트와 편수를 한눈에 보여줍니다.
   - 원하는 제목을 터치하면 해당 야사 본문 카드로 부드럽게 스크롤 이동하며 테두리 강조 효과가 나타납니다.

3. **🗂️ 5대 테마 카테고리 필터**
   - **전체 (`all`)**: 선택한 날짜의 모든 야사 열람
   - **기이한 일 (`mystery`)**: 실록에 기록된 UFO(미확인 비행체), 궁궐 괴물, 기상이변, 귀신 소동
   - **궁중 비화 (`scandal`)**: 왕실의 은밀한 연애사, 독살 의혹, 권력 암투
   - **야담·기인 (`folklore`)**: 《어우야담》·《대동야승》 속 도술 부리는 기인, 해학과 민담
   - **왕의 일상 (`episode`)**: 임금님의 수라상 먹방, 말실수, 사관(史官)과의 신경전
   - **명장면 모음 (`legends`)**: 날짜에 관계없이 조선시대 최고의 레전드 야사 전체 모아보기

4. **🏛️ 정사(실록 원문) + 야사(이야기) 입체 구성**
   - 각 이야기마다 《조선왕조실록》의 실제 기록(`officialRecord`)과 《대동야승》·《어우야담》·《연려실기술》 등을 바탕으로 재구성한 생생한 야사 본문(`yasaStory`)을 함께 수록했습니다.

5. **📖 종이책 감성의 미니멀 리더 UI & 다크 모드**
   - 스마트폰 화면에서도 가로 스크롤이나 깨짐 없이 편안하게 읽을 수 있는 한지(韓紙) 톤 라이트 모드 및 야간 독서용 다크 모드(`🌙` / `☀️`)를 지원합니다.

6. **🔔 오늘 야사 알림받기 (텔레그램 & 브라우저 알림)**
   - 상단의 `🔔 오늘 야사 알림받기` 버튼을 누르면 해당 날짜에서 가장 흥미도가 높은 대표 야사를 알림으로 전송합니다.

## 🚀 실행 방법 (How to Run)

### 1. 웹 브라우저에서 바로 열기 (서버 없이 실행 가능)
정적 웹앱으로 설계되어 있어 별도 빌드 과정 없이 [`index.html`](./index.html)을 브라우저에서 바로 열거나 GitHub Pages 주소로 접속하면 즉시 동작합니다.

### 2. 로컬 Node.js 서버로 실행하기 (텔레그램 API 연동 포함)
```bash
node server.js
# 접속 주소: http://localhost:3456
```
